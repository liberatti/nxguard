# Directrizes de Internacionalização (i18n)

## Diretrizes Gerais
- Nenhuma string visível ao usuário deve ser escrita em hardcode.
- Idioma padrão (fallback): `en-US`.
- Padrão de chaves: `MODULO.FUNCIONALIDADE.NOME_DA_CHAVE`.

---

## 1. Frontend (Angular)

- **Biblioteca:** `@ngx-translate/core`.
- **Templates (HTML):** Use o pipe `translate`.
  ```html
  <h1>{{ 'AUTH.LOGIN_TITLE' | translate }}</h1>
  <p>{{ 'PROJECTS.TOTAL_COUNT' | translate:{ count: total } }}</p>
